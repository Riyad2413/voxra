# Voxra V1 Ready-to-build project

Contains Flutter source and GitHub Actions workflow.

**Prototype limitations:** Login is local demo only, friends are sample data, calls are not real internet calls, and voice style buttons do not alter microphone audio yet.

## GitHub Actions
Upload the CONTENTS of this ZIP to the repository root (not the ZIP itself). Keep `.github/workflows/build-apk.yml`. Then open Actions → Build Voxra APK → Run workflow. Download the `Voxra-V1-APK` artifact after the workflow succeeds.
